# Tiny

URL shortener with QR code generation. **Live:** [tiny.kevinprk.com](https://tiny.kevinprk.com)

## Features

| Feature | Description |
|---------|-------------|
| **URL shortening** | Generate a short link for any URL instantly |
| **QR codes** | Generate a QR code for any shortened link |
| **Analytics** | Track click counts per link |

## Getting Started

```bash
# API (Go)
cd api && go run ./cmd

# Frontend (separate terminal)
cd web && npm install && npm run dev   # http://localhost:3000
```
